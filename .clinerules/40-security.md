# Безопасность (пункт ревью)

- SQL — только ORM/параметризованные запросы, без конкатенации.
- Каждый эндпоинт проверяет JWT и роли (RBAC); нет IDOR (чужой ID недоступен).
- XSS — экранирование вывода; нет command injection (`shell_exec`/`exec` с пользовательским вводом).
- ПДн не логировать; секреты не в git.
- Дозировки/расчёты — строго по ТЗ (медицинский домен), без «творческих» правок.
- Полный чек-лист: `docs/09-Служебное/Регламенты/Security-чеклист.md`.
