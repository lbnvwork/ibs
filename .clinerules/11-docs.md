# Правила документации

- Документация живёт в отдельном репо `ibs-docs` (НЕ в репо кода `ibs`). После переноса в репо кода папки `docs/` нет.
- `ibs-docs` — общий репо: у каждого агента в каталоге `docs/` — его клон; все имеют доступ и право пушить документацию.
- Обсидиан руководителя работает только из папки РП (`ibs-pm-jan/docs/`).
- Правки документации — агент **не коммитит**: правит файлы и присылает руководителю **название коммита**.
- **Пуш** в `ibs-docs` — агент выполняет **по отмашке руководителя**, свободно, **без PR**.
- Порядок: агент правит файлы (в т.ч. пишет отчёт в «Комментарии» задачи) → шлёт название коммита → руководитель коммитит → агент по отмашке пушит.
- Руководитель читает правки в Obsidian (папка РП `ibs-pm-jan/docs/`).
- Именование и структура — по справочнику `docs/README` (завести при переносе).
- До переноса: документация ещё в этом репо — правки доку идут тем же порядком (отчёт → коммит руководителя, без PR).
