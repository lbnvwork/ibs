# Воркфлоу и статусы

- Конвейер: РП → Аналитик → Лид → Дев+Тест → Ревью(Лид) → Тест → Merge/DevOps. Полная схема: `docs/09-Служебное/Регламенты/Воркфлоу.md`.
- Статусы задачи: `spec → planned → in_progress → review → testing → deploy → done` (+`blocked`, `cancelled`).
- WIP: 1–2 задачи в работе на агента.
- **Перед каждым коммитом — остановись, дай отчёт + название коммита, жди подтверждения руководителя.**
- Смена статуса — в канбане + комментарием в статье задачи (`ДД.ММ.ГГ Кто: текст → кому`).
- Не раздувай задачу: существенная доработка = новая задача. Эскалация: Дев/Тест → Лид → РП → Руководитель.
