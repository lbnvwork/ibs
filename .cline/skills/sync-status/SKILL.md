# Sync-status (актуализация статусов)

Держи Канбан и оперативные статусы в актуальном состоянии после каждого мержа.

## Структура (2 документа)
- **Канбан** (`docs/03-Задачи/Канбан.md`) — единственный источник истины по статусам. **Двигает только РП.**
- **«Текущий спринт»** (`docs/03-Задачи/Планы спринтов/Текущий спринт.md`) — оперативно: название/исполнитель/статус.
- **«Детальный план спринтов»** (`docs/03-Задачи/Планы спринтов/Детальный план спринтов.md`) — подробно: цель/KPI/FUNC/оценка/спринт/приоритет/зависимости. **Без статусов и исполнителей.**
- **«Общий план спринтов»** — roadmap/легенда (этапы, дедлайны, покрытие FUNC).

## Шаги
1. Определи задачу по PR: `gh pr view <N>` (title / branch / files).
2. Обнови `docs/03-Задачи/Канбан.md` — передвинь карточку в нужную колонку.
3. Обнови frontmatter `status:` в статье задачи.
4. Обнови статус в `docs/03-Задачи/Планы спринтов/Текущий спринт.md`.
5. Добавь комментарий в «Комментарии» статьи: `ДД.ММ.ГГ Кто: текст → кому`.

## Перенос задачи в другой спринт
- В «Текущем спринте» пометь задачу ⛔ (отменена в текущем спринте).
- В «Детальном плане» перенеси в целевой спринт **с новым номером** (напр. 3.49 → 5.8).
- Документов «Задачник всего» и «Будущие спринты» больше нет — не ссылайся на них.

## Переход на новый спринт
- «Текущий спринт» переименуй в «Спринт N» и положи в `docs/03-Задачи/Планы спринтов/Пройденные спринты/`.
- Заведи новый «Текущий спринт» из набора задач целевого спринта в «Детальном плане».

## Триггеры
- Руководитель отписал «смержил #N».
- По запросу — полная сверка (как при ревью спринта).

## Статусы
- ⬜ todo · 🔄 in_progress · 👀 review · 🧪 testing · ✅ done · ⛔ cancelled
