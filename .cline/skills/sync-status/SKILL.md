# Sync-status (актуализация статусов)

Держи Канбан и планировщик в актуальном состоянии после каждого мержа.

## Шаги
1. Определи задачу по PR: `gh pr view <N>` (title / branch / files).
2. Обнови `docs/03-Задачи/Канбан.md` — передвинь карточку в нужную колонку.
3. Обнови `docs/02-Аналитика/План спринтов.md` — статус задачи.
4. Обнови frontmatter `status:` в статье задачи.
5. Добавь комментарий в «Комментарии» статьи: `ДД.ММ.ГГ Кто: текст → кому`.

## Триггеры
- Руководитель отписал «смержил #N».
- По запросу — полная сверка (как при ревью спринта).

- ⬜ todo · 🚧 in_progress · 👀 review · ✅ done
