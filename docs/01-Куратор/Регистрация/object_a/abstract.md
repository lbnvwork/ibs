# Реферат — Регистрационный объект A

> Рабочее название. Официальное название уточняется у куратора проекта.

## Название программы

Модуль поддержки принятия врачебных решений по дозированию варфарина

## Аннотация

Программа предназначена для поддержки принятия врачебных решений при подборе
дозировки антикоагулянта варфарина. Область применения — клиническая практика,
автоматизированное рабочее место врача и интеграция с лабораторными данными.
Функциональные возможности: расчёт рекомендаций по дозированию на основе значений
МНО, учёт фармакогенетических факторов и генетических маркеров пациента, сбор,
хранение и отображение витальных показателей, формирование вариантов дозы с
пояснениями для врача.

## Тип реализующей ЭВМ

Сервер архитектуры x86-64 (совместимый), клиент — персональный компьютер с
веб-браузером.

## Язык программирования

PHP 8.2 (Symfony 7.3, API Platform 4), JavaScript (Vue 3, Vite, Pinia).

## Вид и версия операционной системы

Ubuntu 22.04 LTS (серверная часть); клиентская часть работает в веб-браузере.
