# Данные для официальной формы заявки — Регистрационный объект A

> Структурированные сведения для заполнения официальной формы заявки на
> регистрацию программы для ЭВМ. Саму форму заполняет куратор/патентовед.
> Поля, помеченные «—» или «ожидается», требуют уточнения у куратора.

## Название программы

**Рабочее:** Модуль поддержки принятия врачебных решений по дозированию варфарина

**Официальное (для формы):** ожидается от куратора

## Правообладатель

Ожидается от куратора (юридическое/физическое лицо, реквизиты).

## Авторы

Ожидается от куратора (ФИО, должности, вклад).

## Дата создания

Ожидается от куратора (дата завершения разработки / первого выпуска).

## Краткое описание

Модуль поддержки принятия врачебных решений (CDSS) для подбора дозировки
варфарина: расчёт рекомендаций дозировки на основе значений МНО, учёт
фармакогенетических факторов и генетических маркеров пациента, сбор и
отображение витальных показателей, формирование вариантов дозы с пояснениями
для врача.

## Контактные данные

Ожидаются от куратора (адрес, телефон, e-mail заявителя).

## Прочие сведения для формы

- Тип ЭВМ: сервер x86-64, клиент — ПК с веб-браузером.
- Язык: PHP 8.2, JavaScript (Vue 3).
- ОС: Ubuntu 22.04 LTS.
- Объём исходного кода: 71.3 КБ (73 018 байт).
- Распечатка исходного кода: `printout/printout.pdf` (52 страницы).
