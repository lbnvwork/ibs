# Реферат — Регистрационный объект B

> Рабочее название. Официальное название уточняется у куратора проекта.

## Название программы

Медицинская информационная система ведения терапии варфарином

## Аннотация

Программа предназначена для ведения медицинской информационной системы терапии
варфарином. Область применения — медицинские организации, автоматизация рабочего
места врача и медицинского персонала. Функциональные возможности: ведение реестра
пациентов и медицинского персонала, назначения и приёмы, история анализов и
диагнозов, управление лечением, отправка уведомлений и сообщений, разграничение
доступа, а также клиентская часть для работы врача.

## Тип реализующей ЭВМ

Сервер архитектуры x86-64 (совместимый), клиент — персональный компьютер с
веб-браузером.

## Язык программирования

PHP 8.2 (Symfony 7.3, API Platform 4), JavaScript (Vue 3, Vite, Pinia).

## Вид и версия операционной системы

Ubuntu 22.04 LTS (серверная часть); клиентская часть работает в веб-браузере.
