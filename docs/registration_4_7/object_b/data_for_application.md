# Данные для официальной формы заявки — Регистрационный объект B

> Структурированные сведения для заполнения официальной формы заявки на
> регистрацию программы для ЭВМ. Саму форму заполняет куратор/патентовед.
> Поля, помеченные «—» или «ожидается», требуют уточнения у куратора.

## Название программы

**Рабочее:** Медицинская информационная система ведения терапии варфарином

**Официальное (для формы):** ожидается от куратора

## Правообладатель

Ожидается от куратора (юридическое/физическое лицо, реквизиты).

## Авторы

Ожидается от куратора (ФИО, должности, вклад).

## Дата создания

Ожидается от куратора (дата завершения разработки / первого выпуска).

## Краткое описание

Медицинская информационная система ведения терапии варфарином: ведение реестра
пациентов и медицинского персонала, назначения и приёмы, история анализов и
диагнозов, управление лечением, отправка уведомлений и сообщений, разграничение
доступа, а также клиентская часть для работы врача.

## Контактные данные

Ожидаются от куратора (адрес, телефон, e-mail заявителя).

## Прочие сведения для формы

- Тип ЭВМ: сервер x86-64, клиент — ПК с веб-браузером.
- Язык: PHP 8.2, JavaScript (Vue 3).
- ОС: Ubuntu 22.04 LTS.
- Объём исходного кода: 211.4 КБ (216 456 байт).
- Распечатка исходного кода: `printout/printout.pdf` (67 страниц, отобраны
  фрагменты из 115 файлов исходного кода).
