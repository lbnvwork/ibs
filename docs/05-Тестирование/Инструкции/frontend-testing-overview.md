## Известные задокументированные (не исправленные) особенности
- `calculateAge()` возвращает `NaN` (не `null`) для нераспознаваемой строки даты — поведение зафиксировано тестом намеренно, не менялось (безобидный краевой случай, не влияющий на реальные данные).

## Баги, найденные и исправленные благодаря тестам
1. `pharmacogeneticsStore.save()` затирал сообщение об ошибке повторной загрузкой данных после неудачного сохранения (порядок операций был неверным).
2. `TreatmentAdd.script.js` вызывал `validateForm()` без импорта функции — ломало отправку формы добавления лечения (используется сразу после создания каждого нового пациента).
3. `PatientCard`/`TreatmentCard`: кнопки редактирования/отмены были привязаны напрямую к методам стора в обход собственных методов компонента, из-за чего события `edit-start`/`edit-end` не долетали до родительского `MedicalHistory.vue`, и раздел не разворачивался автоматически при входе в режим редактирования.
