# Аквариум (трассировка кода в стиле дебаггера)

«Аквариум» — путеводитель по коду фичи: читатель проходит по сценарию, как в дебаггере, и видит движение данных, содержимое переменных и логику переходов. Это не карта вызовов «функция → функция», а разбор «что происходит и почему».

## Канон формата
Полный формат и разобранный пример (сценарий отправки уведомления в MAX) — в скилле `write-aquarium` (`.cline/skills/write-aquarium/SKILL.md`).

## Кратко
- **«Идея»** в начале: что делает фича + какими паттернами/технологиями.
- **Один сценарий = один проход по коду**: Вход → шаги → Выход.
- **Каждый шаг**: вызов функции + фактические значения переменных + русское объяснение.
- **Паттерн/архитектурное решение** встроено в шаг («почему так»).
- **Движение данных** прослеживается от входа к выходу (например `patientId=42 → chat_id → тело POST → notification_logs`).
