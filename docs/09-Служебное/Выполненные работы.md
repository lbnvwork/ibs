 ИБС:
- В карточке пациента теперь можно вводить результаты генетических тестов (CYP2C9, VKORC1). Система показывает, как эти гены влияют на чувствительность к варфарину.
    
- Добавлен ввод и отображение показателей здоровья (гемоглобин, пульс, артериальное давление, сатурация, вес). Они видны и в карточке пациента, и на дашборде врача.
    
- Таблица истории болезни стала компактнее: все измерения и анализы за день выводятся в одной строке.
    
- Назначения теперь связаны с SMS-уведомлениями: врач видит в истории текст сообщения, которое получил пациент по каждому назначению.
    
- Интерфейс карточки пациента улучшен: блоки с информацией сворачиваются, показывая самое важное, и экономят место на экране.
    
- Продолжена подготовка данных для системы автоматического подбора дозы варфарина.
    
- Начат этап настройки оповещений пациентов и врачей (SMS, email, push-уведомления).
ИМР: 
- Создан модуль, который принимает от лабораторных систем электронные протоколы исследований (формат CDA редакции 5).
    
- При получении документа автоматически проверяется его корректность по утверждённым схемам. Документы с ошибками отклоняются, а причина отказа сохраняется.
    
- Из успешно проверенного протокола извлекаются нужные клинические данные: СНИЛС пациента, код теста (пока поддерживается только МНО), значение результата, дата исследования и другие показатели, если они есть.
    
- Все входящие документы и извлечённые данные сохраняются в базе, доступны для просмотра администратором через удобную команду.
    
- Настроена безопасная передача данных: лабораторная система получает временный ключ доступа, без которого отправка документов невозможна.
    
- Реализована возможность быстро добавлять новые лаборатории-отправители через простую консольную команду.
    
- Проведено полное тестирование на работающем стенде: успешно передан корректный протокол с анализом МНО, отклонены документы с ошибками или без обязательного теста.
    
- Для разработчиков лабораторных систем подготовлено понятное руководство по подключению и готовая коллекция запросов.
