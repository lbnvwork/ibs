# Статусы задач и WIP-лимиты

## Алфавит статусов

| Статус | Значение | Кто двигает |
|---|---|---|
| `spec` | формируется постановка | Аналитик |
| `planned` | спланировано, готово к реализации | Лид |
| `in_progress` | в работе | Дев |
| `review` | на ревью | Лид |
| `testing` | тестируется | Тестировщик |
| `deploy` | деплой на тестовый | DevOps |
| `done` | завершено и смёржено | Руководитель |
| `blocked` | заблокировано, нужно решение | РП |
| `cancelled` | отменено | РП/Руководитель |

Основной поток: `spec → planned → in_progress → review → testing → deploy → done`.

## WIP-лимиты

- **1–2 задачи в `in_progress`** на одного агента.
- Не начинать новую задачу, пока не сдана текущая (или она не в `blocked`).

## Смена статуса

- Фиксируется в канбане и **комментарием** в статье задачи: «Беру в работу», «Передаю на ревью → Лид» и т.п.
