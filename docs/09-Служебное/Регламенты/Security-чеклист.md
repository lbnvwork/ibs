# Security-чеклист (обязательный пункт ревью)

Проверяется Лидом на ревью и Девом при реализации.

## Инъекции

- [ ] SQL — только через ORM/параметризованные запросы, без конкатенации SQL.
- [ ] XSS — экранирование/санитизация вывода.
- [ ] Command injection — нет `shell_exec`/`exec` с пользовательским вводом.

## Аутентификация и авторизация

- [ ] Каждый эндпоинт проверяет JWT и роли (RBAC).
- [ ] Нет IDOR: доступ к чужой сущности по ID запрещён (проверка владельца/роли).

## ПДн и секреты

- [ ] ПДн не логируется и не попадает в сообщения об ошибках.
- [ ] Секреты (токены, пароли) не в git и не в коде — только `.env`/переменные окружения.

## Зависимости и ввод данных

- [ ] Нет новых уязвимых зависимостей (`composer audit`, `npm audit`).
- [ ] Валидация входящих данных (Assert-ограничения, типы).

## Медицинский домен (обязательно)

- [ ] Дозировки/расчёты соответствуют ТЗ (варфарин, МНО, ПОАК) — клиническая корректность.
- [ ] Никаких «творческих» изменений медицинской логики без согласования с руководителем.
