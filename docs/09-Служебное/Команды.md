# Команды (публичная версия, без секретов)

> Секреты, IP серверов и пароли — в `docs/Доступы/` (локально, в git не попадает).

## Локальный запуск / остановка

```bash
docker compose up -d --build   # запустить (с пересборкой)
docker compose down            # остановить и удалить контейнеры
docker compose up              # запустить без пересборки
```

> У каждого агента свой стек и порты (см. таблицу ниже). Запускать из своего каталога.

## Выполнить команду / войти в контейнер

```bash
docker compose exec php <команда>     # выполнить команду в php-контейнере
docker compose exec php bash          # войти в контейнер
docker compose exec db psql -U symfony -d symfony   # войти в PostgreSQL
```

## Миграции

```bash
docker compose exec php bin/console make:migration
docker compose exec php bin/console doctrine:migrations:migrate
docker compose exec php bin/console doctrine:migrations:migrate DoctrineMigrations\\VersionXXXX --down
```

## Кэш и схема БД

```bash
docker compose exec php bin/console cache:clear
docker compose exec php bin/console doctrine:schema:validate
```

## Авторизация (JWT)

```bash
curl -X 'POST' 'http://localhost:8081/api/login' \
  -H 'accept: application/json' \
  -H 'Content-Type: application/json' \
  -d '{ "login": "<ЛОГИН>", "password": "<ПАРОЛЬ>" }'

# далее использовать полученный JWT:
curl -X GET 'http://localhost:8081/api/test_histories' \
  -H 'Authorization: Bearer <JWT_ТОКЕН>'
```

## Экспорт

```bash
docker compose exec db sh -c "pg_dump -U \$POSTGRES_USER -d \$POSTGRES_DB --schema-only" > schema.sql
docker compose exec php bin/console api:openapi:export > openapi.json
```

## Деплой на VPS (общие шаги)

```bash
ssh root@<IP_СЕРВЕРА>          # IP — в docs/Доступы/
cd /var/www/ibs
git pull origin develop
docker compose exec php bin/console doctrine:migrations:migrate --no-interaction --allow-no-migration
docker compose exec php bin/console cache:clear --env=prod --no-debug
docker compose exec php bin/console cache:warmup --env=prod
systemctl reload nginx
```
