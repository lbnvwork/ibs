# 3.19. Настройка Cline (v4.1.11): правила, навыки, вводные агентов

## Цель
Настроить Cline под модель «1 чат = 1 агент»: роль каждого агента — через правила в его каталоге, общие возможности — через навыки. (Agent Teams для VS Code недоступен — только CLI/SDK/Kanban; cline-cli отложен.)

## Задача
1. **Верификация** на одном каталоге (`ibs-pm-jan`): убедиться, что `.clinerules/*.md` подхватывается (Rules-панель Cline) — тестовое правило + проверка руководителем.
2. **Общие правила** в `.clinerules/*.md` (коммитим в develop): `10-git.md`, `20-workflow.md`, `30-tdd.md`, `40-security.md`, `50-dod.md`.
3. **Роль** агента — `.clinerules/00-role.md` в его каталоге (уникальное, gitignored): роль → зона ответственности → этапы конвейера → куда писать → ссылки на регламенты. 7 файлов: РП, аналитик, тестировщик, лид, dev-may, dev-jun, devops.
4. **Навыки** `~/.cline/skills/<имя>/SKILL.md` (frontmatter `name`+`description`): `git-workflow`, `run-tests`, `write-adr`, `write-e2e-scenario`, `make-postman`, `explain-db`, `write-instruction`.
5. Удалить старые `.cline/rules.md` (7 шт) и плоские `~/.cline/skills/*.md`.
6. В вводных (ролях) агентов прописать: по завершении задачи агент сам создаёт PR — `gh pr create`, шаблон `_Шаблоны/PR.md`, заголовок `S.NN Название`; руководитель ревьюит и мёржит.
7. **Навыки**: версионировать в git (`.cline/skills/`), добавить секцию «Навыки» в шаблон задачи и в инструкцию.

## Результаты исследования (22.08.26)
- **Agent Teams** — только CLI/SDK/Kanban, для VS Code-расширения недоступен → не подходит, остаёмся на «1 окно = 1 агент».
- **Subagents** — read-only «исследователи» (файлы писать не могут) → не для наших пишущих агентов.
- **cline-cli** — headless-режим для автоматизации → отложен (позже для пакетных задач).
- **Правила**: проект `.clinerules/` (или `.cline/rules/`), глобально `~/.cline/rules/` / `~/Documents/Cline/Rules`.
- **Навыки**: `.cline/skills/<имя>/SKILL.md` / `~/.cline/skills/<имя>/SKILL.md`.
- **Контекст**: окно ~1M токенов + **Auto Compact** (автосуммаризация при заполнении; на не-Claude моделях — простое усечение). Для долгих чатов: **1 задача = 1 сессия**, постоянная память — Obsidian (задачи/регламенты/вводные) как Memory Bank.
