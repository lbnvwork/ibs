# 3.19. Настройка Cline (v4.1.11): правила, навыки, вводные агентов

## Цель
Настроить Cline правильно (прошлая настройка `.cline/rules.md` и плоские skills не подхватываются).

## Задача
1. **Общие правила** в `.clinerules/*.md` (коммитим в develop): `10-git.md`, `20-workflow.md`, `30-tdd.md`, `40-security.md`, `50-dod.md`.
2. **Роль** агента — `.clinerules/00-role.md` в его каталоге (уникальное, gitignored): роль → зона ответственности → действия на каждом этапе конвейера → вход/выход → куда писать → ссылки на регламенты. 7 файлов: РП, аналитик, тестировщик, лид, dev-may, dev-jun, devops.
3. **Навыки** `~/.cline/skills/<имя>/SKILL.md` (frontmatter `name`+`description`): `git-workflow`, `run-tests`, `write-adr`, `write-e2e-scenario`, `make-postman`, `explain-db`, `write-instruction`.
4. Удалить старые `.cline/rules.md` (7 шт) и плоские `~/.cline/skills/*.md`.
5. В вводных (ролях) агентов прописать: по завершении задачи агент сам создаёт PR — `gh pr create`, шаблон `_Шаблоны/PR.md`, заголовок `S.NN Название`; руководитель ревьюит и мёржит.

## Критерии приёмки
- [ ] Правила видны в Rules-панели Cline
- [ ] Навыки видны в Skills-меню
- [ ] Роли подхватываются при старте чата
- [ ] В вводных прописано создание PR по завершении задачи

## Результат
Настроенный Cline + 7 вводных + общие навыки.
