# 3.17. Шаблоны документов

## Цель
Единые шаблоны, по которым все агенты пишут свои артефакты.

## Задача
Создать в `03-Задачи/_Шаблоны/`:
1. `Задача.md` — frontmatter + секции: Основание / Бизнес-логика / Сценарии / Финальная постановка / Тесты (TDD) / Реализация / Аквариум / Ручное тестирование / Статья-инструкция (DoD) / Результат.
2. `ADR.md` — контекст, решение, альтернативы, последствия.
3. `E2E-сценарий.md` — Given/When/Then + «вход → трасса → выход».
4. `Статья-инструкция.md` — назначение, шаги, примеры, чек-лист.

## Критерии приёмки
- [ ] Шаблоны созданы, frontmatter валиден
- [ ] По каждому шаблону агент понимает, что и куда писать

## Результат
4 шаблона в `03-Задачи/_Шаблоны/`.
