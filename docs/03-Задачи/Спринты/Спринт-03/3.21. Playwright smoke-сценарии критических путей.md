# 3.21. Playwright: smoke-сценарии критических путей

## Основание
Нужен первый набор E2E-тестов критических путей, чтобы нейротестировщик мог проверять контуры в браузере.

## Цель
3–5 зелёных smoke-сценариев + отчёт.

## Задача
1. Изучить приложение через свой стек (`localhost:8005`): авторизация → список пациентов → карточка пациента → МНО.
2. Определить 3–5 критических путей (вход; открытие списка; карточка с МНО; создание пациента; добавление лечения).
3. Написать Playwright-тесты (TypeScript) в `tests/e2e/`, добиться зелёных.
4. Приложить trace/скриншоты; кратко описать сценарии в `docs/05-Тестирование/Сценарии-E2E/`.
5. Критически оценить сценарии: предложить новые, отметить риски (позитив/негатив).

## Критерии приёмки
- [ ] 3–5 smoke-тестов проходят
- [ ] Сценарии описаны в `05-Тестирование/Сценарии-E2E/`
- [ ] trace/скриншоты приложены
- [ ] Блок «Ручное тестирование» добавлен в статью задачи

## Результат
Работающий smoke-набор Playwright.
