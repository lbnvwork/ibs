# 3.18. Регламенты работы команды

## Цель
Зафиксировать правила работы команды, чтобы нейроагенты действовали одинаково.

## Задача
Создать в `09-Служебное/Регламенты/`:
1. `Воркфлоу.md` — конвейер (схема Mermaid): РП → Аналитик → Лид → Тестировщик+Дев → Ревью(лид) → Тест → Merge/DevOps, с ролями и артефактами.
2. `Статусы.md` — алфавит статусов `spec → planned → in_progress → review → testing → deploy → done` (+blocked/cancelled), WIP-лимит 1–2 на агента.
3. `Git-конвенции.md` — ветки от develop, формат коммитов (`3.16. doc new ...`), PR на develop, ревью лидом.
4. `Эскалация.md` — обратная связь, меняющая сценарии → РП с таймаутом; «не раздуваем задачу — выносим в новую».
5. `Security-чеклист.md` — инъекции, права, утечка ПДн, IDOR — пункт ревью.

## Критерии приёмки
- [ ] 5 документов готовы
- [ ] Каждый агент ссылается на регламенты из своей вводной

## Результат
5 регламентов в `09-Служебное/Регламенты/`.
