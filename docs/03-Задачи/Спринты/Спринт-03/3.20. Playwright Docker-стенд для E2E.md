# 3.20. Playwright: Docker-стенд для E2E

## Основание
Команда переходит на Playwright для E2E-тестов. Тестировщику нужен стенд, где тесты гоняются в Docker против поднятого приложения.

## Цель
Рабочий e2e-контейнер + инструкция по запуску.

## Задача
1. В общий `docker-compose.yml` добавить сервис `e2e` на базе официального образа `mcr.microsoft.com/playwright` (chromium), подключённый к сети стека. Правь файл у себя в каталоге — изменения дойдут до всех агентов через PR (тесты гоняет Марк из `ibs-tester-mar`).
2. baseURL на nginx стека (`http://nginx` внутри сети), headless, включить screenshot + trace.
3. Структура `tests/e2e/` с `playwright.config.ts` и плейсхолдер-тестом.
4. Запуск: `docker compose run --rm e2e npx playwright test`; артефакты (trace/скриншоты) — в volume/папку.
5. Инструкция в `docs/06-DevOps/Инструкции/Playwright-стенд.md` (запуск, просмотр trace).

## Реализация
- **Сервис общий** — `e2e` добавлен в общий `docker-compose.yml` (в git); Марта использует его в `ibs-tester-mar` без дублирования, образ автоформируется как `${COMPOSE_PROJECT_NAME}-e2e` (без явного `image:`).
- **Тонкий `Dockerfile` поверх официального образа** `mcr.microsoft.com/playwright:v1.62.0-noble`: образ содержит браузеры и системные зависимости, но не npm-пакет — `@playwright/test@1.62.0` ставится через `npm ci` (версия обязана совпадать с версией браузеров).
- **`ENV PLAYWRIGHT_SKIP_BROWSER_DOWNLOAD=1`** — браузеры уже в базовом образе (`/ms-playwright`), отключена их повторная загрузка при postinstall.
- **`ipc: host`** — chromium в Docker требует общего IPC (иначе возможны падения по памяти).
- **Артефакты** — `screenshot: 'on'`, `trace: 'on'`, `outputDir: 'test-results'`; через bind-mount `./tests/e2e:/e2e` trace/скриншоты попадают в `tests/e2e/test-results/` на хосте (в git не идут).
- **`e2e_node_modules`** — named volume поверх bind-mount, чтобы `node_modules` из образа не перекрывался живой папкой `tests/e2e`.
- **Запуск** — стек поднимается заранее (`docker compose up -d`), тесты — `docker compose run --rm e2e npx playwright test`; сервис вынесен в профиль `e2e`, чтобы `docker compose up` его не запускал (без `depends_on`).
