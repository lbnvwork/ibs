# 3.20. Playwright: Docker-стенд для E2E

## Основание
Команда переходит на Playwright для E2E-тестов. Тестировщику нужен стенд, где тесты гоняются в Docker против поднятого приложения.

## Цель
Рабочий e2e-контейнер + инструкция по запуску.

## Задача
1. В каталоге тестировщика (`ibs-tester-mar`) добавить в docker-compose сервис `e2e` на официальном образе `mcr.microsoft.com/playwright` (chromium), подключённый к сети стека.
2. baseURL на nginx стека (`http://nginx` внутри сети), headless, включить screenshot + trace.
3. Структура `tests/e2e/` с `playwright.config.ts` и плейсхолдер-тестом.
4. Запуск: `docker compose run --rm e2e npx playwright test`; артефакты (trace/скриншоты) — в volume/папку.
5. Инструкция в `docs/06-DevOps/Инструкции/Playwright-стенд.md` (запуск, просмотр trace).

## План реализации (чек-лист коммитов)
- [x] 1. Скелет `tests/e2e/` (config, плейсхолдер-тест, Dockerfile, package.json) — `3.20 test new`

- [ ] 3. Инструкция `docs/06-DevOps/Инструкции/Playwright-стенд.md` — `3.20 doc new`
