# 3.23. Настройка gh CLI и процесса пул-реквестов агентов

## Основание
Решено: агенты сами создают пул-реквесты, руководитель только ревьюит и мёржит. Нужна настройка `gh` и инструкция.

## Задача
1. Проверить/установить GitHub CLI (`gh`).
2. Настроить авторизацию `gh auth login` (один раз на пользователя `max` — под ним работают все агенты).
3. Проверить связку `git push` (SSH) + `gh pr create`.
4. Написать инструкцию в `06-DevOps/Инструкции/Создание-PR.md`: команда создания, ссылка на шаблон `_Шаблоны/PR.md`, конвенция заголовка `S.NN Название`.

## Критерии приёмки
- [ ] `gh pr create` работает из любого каталога агента
- [ ] Инструкция написана
- [ ] Тестовый PR создан и закрыт без мержа (проверка процесса)

## Результат
Агенты создают PR; руководитель ревьюит и мёржит.
