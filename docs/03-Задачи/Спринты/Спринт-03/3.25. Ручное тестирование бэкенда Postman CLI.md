# 3.25. Ручное тестирование бэкенда: Postman CLI

## Основание
Тестировщику нужен способ гонять бэкенд (Symfony API Platform) вручную — не все задачи браузерные. Сейчас скилл `make-postman` только создаёт коллекции, но не выполняет их. Решение — Postman CLI (`postman`): агент гоняет коллекции/запросы с хоста на `localhost:8005`. Postman MCP отложен до тестирования на VPS.

## Навыки (Skills)
`git-workflow`, `run-tests`, `make-postman`, `write-instruction`

## Задача
1. Установить Postman CLI на хост (`npm install -g @postman/postman-cli`).
2. Инструкция `docs/06-DevOps/Инструкции/Postman-CLI.md`: установка, `postman login`, `postman collection run` против `localhost:8005`, `postman request send`.
3. (Макс) `postman login` — разовая авторизация через браузер.
4. (Ян) Расширить скилл `make-postman`: генерация коллекции + прогон `postman collection run` + curl-фолбэк + импорт OpenAPI (`/api/docs.json`).
5. (Марк) Пробный прогон на 3.1: коллекция + результат в «Ручное тестирование».

## Критерии приёмки
- [ ] Postman CLI установлен, `postman --version` работает
- [ ] Инструкция `Postman-CLI.md` написана
- [ ] `postman login` выполнен (Макс)
- [ ] Скилл `make-postman` расширен (прогон + curl + OpenAPI)
- [ ] Пробный прогон коллекции против `localhost:8005` — зелёный

## Результат
Марк гоняет бэкенд через Postman CLI; коллекции синхронизируются с Postman-облаком.
