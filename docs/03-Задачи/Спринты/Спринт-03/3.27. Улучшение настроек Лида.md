# 3.27. Улучшение настроек Лида

## Основание
По итогам первого ревью Эйпа — пробелы процесса: (1) замечания записывались в задачу, а не в PR; (2) тесты не запускались (доверие «на слово»). Нужен скилл `review-code` + отражение двух режимов работы Лида в роли.

## Задача
1. Скилл `review-code`: CI-статус (или запуск сам) → замечания в PR → задача = короткий статус → security-чек-лист → системный vs локальный пробел → явный вердикт.
2. Роль Эйпа: 2 режима (подготовка к реализации / ревью) + навык `review-code`.
3. Правило «код-замечания → PR, задача → короткий коммент» в `20-workflow.md`.

## Критерии приёмки
- [ ] Скилл `review-code` создан
- [ ] Роль Эйпа отражает 2 режима
- [ ] Правило зафиксировано в `20-workflow.md`

## Результат
Процесс ревью закреплён: ревьюер проверяет тесты и пишет замечания в PR.
